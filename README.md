# 瑶纹工坊 · 瑶绣纹样数字化交互应用

纯前端 H5 应用：瑶绣纹样的**数字化保护**、**可控式创意表达**与**交互化传承**。
零依赖、零后端、零外部请求——`index.html` 双击即可运行，也可托管到任意静态平台（GitHub Pages / Vercel / 对象存储）。

## 功能

### 纹样数字基因库（`#/gene`）

- 7 款瑶绣纹样高清数字化图像（base64 内嵌，离线可用）
- 支系 / 主题双维度筛选 + 瀑布流卡片
- 详情页：文化寓意、使用场景、分级管控、传承人溯源
- **三级分级管控**：一级核心保护纹样（盘王印）仅作展示，不提供下载与二次创作入口

### 纹样创作台（`#/studio`）

- **3 种画布形状**：方形绣片 / 衣服 / 布袋子（生活中常用载体；纹样裁剪在画布轮廓之内）
- 素材拖拽入画、单指拖动、双指缩放旋转、桌面端滚轮缩放
- 传统对称构图辅助（左右 / 上下 / 四方对称，镜像成组移动与删除）
- 文化合规校验引擎：动物纹占比、倒置禁忌、万字纹用量等规则，导出前必须通过
- 导出 1000×1000 PNG，自动附「瑶族传统纹样衍生」溯源水印

## 技术

- 原生 HTML5 + CSS3 + 原生 JavaScript（无框架、无构建步骤）
- 纹样图像：原始大图经 Pillow 优化（长边 ≤720px；扁平图案 128 色量化、照片类 JPEG q82）后以 base64 data URI 内嵌，运行时约 1.4MB
- 响应式：移动端底部 Tab（≥48px 触控）/ 桌面端（≥768px）侧边栏
- 字体：思源宋体 / 黑体均不可内嵌分发，采用系统字体栈回退（Songti SC / Noto Serif SC / SimSun 等）
- 合规红线：核心信仰纹样只读；缺失的传承人信息标「待补充」，不做臆测填写

## 运行

```bash
# 方式一：直接双击 index.html（file:// 协议，已验证可用）

# 方式二：任意静态服务器
python -m http.server 8000
# 打开 http://localhost:8000
```

## 目录结构

```
index.html          入口（脚本顺序：core → gene-images → genes → mod-gene）
css/app.css         设计系统（瑶绣传统色 token + 系统字体栈 + 响应式）
js/core.js          应用骨架（hash 路由 / 工具函数 / Toast / 弹窗 / 导出）
js/genes.js         纹样基因数据 + SVG 渲染 API
js/gene-images.js   纹样素材图（base64 data URI，由原始大图优化生成）
js/mod-gene.js      模块一：纹样图鉴 + 可控创作台
```
